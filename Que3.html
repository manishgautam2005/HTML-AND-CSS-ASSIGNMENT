Terminal Navigation Practice Sheet

Learn essential terminal commands for macOS, Linux, Git Bash, and Windows PowerShell.

1. Terminal Commands

# Task macOS / Linux / Git Bash PowerShell
1 Show current folder pwd pwd
2 List files ls ls
3 List details and hidden files ls -la ls -Force
4 Create a folder mkdir practice mkdir practice
5 Enter a folder cd practice cd practice
6 Create an empty file touch index.html ni index.html
7 Create nested folders mkdir -p css/images mkdir css/images
8 Go up one level cd .. cd ..
9 Go to home directory cd ~ cd ~
10 Copy a file cp index.html backup.html cp index.html backup.html
11 Rename or move a file mv backup.html old.html mv backup.html old.html
12 Delete a file rm old.html rm old.html
13 Delete a folder rm -r css rm -r css
14 Print file contents cat index.html cat index.html
15 Clear the screen clear cls
16 Open folder in VS Code code . code .
Note: In PowerShell, ni is an alias for New-Item. To create nested folders reliably, use mkdir css/images when the parent folder already exists, or create each folder separately. Be careful with delete commands because deleted files may not be recoverable.

2. Practice Exercise

Starting from your home directory, complete these tasks:

  1. Create a website folder containing index.html, css/style.css, and an images folder.
  2. Go into the css folder.
  3. Return to website using one command: cd ...
  4. List all files and folders recursively using ls -R.
  5. Rename index.html to home.html, then rename it back.
  6. Open the project folder in VS Code.

3. Answers / Commands

Run the following commands in order in macOS, Linux, or Git Bash:

cd ~
mkdir -p website/css website/images
touch website/index.html website/css/style.css
cd website/css
cd ..
ls -R
mv index.html home.html
mv home.html index.html
code .

4. Expected Folder Structure

website/
├── index.html
├── css/
│   └── style.css
└── images/

5. What You Learned

  • Navigate between directories using cd.
  • View files using ls and ls -R.
  • Create files and directories using touch and mkdir.
  • Rename files using mv.
  • Open your project in VS Code using code ..
